## Surface Classification for KUKA youBot

Исследование классификации типов подстилающих поверхностей (линолеум, искусственная трава, резиновый и ячеистый ковер) на основе анализа потребления тока двигателями колес робота KUKA youBot.

![Экспериментальная установка](scheme.png)

Решение задачи классификации осуществляется с использованием ***вероятностного подхода***, при котором принадлежность текущего измерения к одному из классов (типов поверхности) определяется на основе степени соответствия наблюдаемых данных заранее построенным аналитическим моделям поверхностей.

![Структурная схема классификатора](classifier.png)

Входными данными являются **угол (направление) движения** робота и **суммарный ток** приводов. На выходе получаем **тип поверхности**, которому соответствует максимальное значение вероятности.
